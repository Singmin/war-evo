# 文明跃迁

一款原创的横版对线推塔 + 时代进化策略游戏，H5 形式发布到 TapTap，手机横屏和电脑浏览器都能玩。

人类文明毁于"大熄灭"后，幸存者分裂成**拾光派**和**余烬派**。两派从部落纪重新起步，一边造兵对战，一边沿着科技树（机械 / 生物 / 火药三条路线，17 个时代，最后有 9 个不同的最终时代）比谁先进化到终点、点亮方舟塔。

## 玩法

两派共用科技路线与兵种。玩家可以把金币用于出兵、发展经济和跃迁。

- **造兵**：兵自动沿战道前进，相遇就交战。每方最多同时上场 15 个兵。击杀得金币和经验，塔和大招的击杀奖励减半。炮兵只能锁定边缘距离超过 80 的敌兵，骑兵用较低生命换更高攻击。
- **空军**：独立飞行队列，近战和炮兵打不到；射手、空军、防御塔和大招能对空。空军打地面兵、敌方空军和基地，攻基地伤害减半，也挡不住地面兵推进，适合配合前排。17 个时代各有飞行、攻击和坠落像素动画。
- **建塔 / 扩塔位 / 强化塔**：稳住防守；每座塔可强化 2 次。
- **采矿场**：投资经济，3 级，每级自动金币 +15%；金币旁边显示每秒收入。
- **科技树**：击杀得经验，经验攒满立刻得科技点，玩家和 AI 同一套。双方跃迁都要花 4 个科技点和金币，AI 费用为玩家的一半。点够并且金币够就立刻开始跃迁，跃迁期间训练暂停 3 秒，青铜纪后分三条路线。
- **大招**：60 秒冷却，弹幕扫过整个战场，随机落点，敌兵越密收益越大；重装一次最多掉 40% 生命。
- **TapTap 激励视频**：科技树里 +1 科技点（不限次）；左上角看广告拿金币（不限次数、无冷却）、基地低于 60% 时看广告回血 30%（冷却 90 秒）。看广告时游戏暂停，完整播放后发放奖励。

摧毁对方基地即获胜。3 倍速的设计目标约为现实 20 分钟，五个阶段的游戏内目标分别为 6、12、12、12、18 分钟。首次开局默认选中简单。调参记录见[难度与节奏调整](design/quick-specs/match-pace-2026-11-13.md)。

## 操作

| 操作 | 电脑 | 手机 |
|---|---|---|
| 出步兵 / 射手 / 骑兵 / 炮兵 / 空军 / 重装 | 按钮或 `1`–`6`（从左到右） | 点一次选中看价格，再点一次确认 |
| 建塔 | 按钮或 `T` + `1 / 2 / 3` | 同上 |
| 强化 / 卖塔 | 改塔菜单 → 选塔位 | 同上 |
| 扩塔位 / 采矿场 | `B` / `G` | 同上 |
| 科技树 / 大招 | `E` / `Q` | 同上（科技树打开时游戏暂停） |
| 滚动镜头 | 拖动或 `A / D` | 在战场左右滑动 |
| 缩放 | 滚轮或 `+ / -` | 双指捏合 |
| 游戏速度 | `F` | 右上角 ×1 / ×1.5 / ×2 / ×3 |
| 暂停 | `Space` | 右上角按钮 |
| 游戏图解 | 点大招下方的「游戏图解」 | 同上（打开时暂停，关闭后继续） |

## 运行

M1 已可以玩：

- **本地调试**：在项目目录起一个静态服务器，再用浏览器打开，例如：

  ```bash
  npx serve .
  ```

- **发布**：把 `index.html`、`css/`、`js/` 一起打包上传到 TapTap H5，详见设计文档第 13 节。
- **广告接入**：TapTap H5 宿主注入 `tap`，广告位 ID 配在 `js/ui/ads.js`。首次启动满 60 秒后可播放激励视频。主菜单和结算页的上下 Banner 在广告加载成功且尺寸合适时展示。上传 H5 包后用 TapTap App 自测广告播放与领奖。

推荐浏览器：新版 Chrome、Edge、Safari；手机请横屏。

## 代码结构

不用打包工具，`index.html` 按顺序加载普通 `<script>`，所有文件共用全局变量。**界面代码按角色分文件**，改哪块界面就去对应文件，不要把界面代码写进规则 / AI 里。

| 文件 | 负责 |
|---|---|
| `index.html` | 页面结构（各个覆盖页面的 HTML）和加载顺序 |
| `css/theme.css` | **主题**：颜色、字号变量（`--gold`、`--fs-m`…），通用按钮和面板。改配色、字号先改这里 |
| `css/layout.css` | 画布缩放、横幅广告和竖屏提示 |
| `css/hud.css` | 局内 DOM 部分：右上按钮、操作提示、看广告按钮 |
| `css/bar.css` | 底部操作栏 |
| `css/screens.css` | 开始页、暂停、设置、战绩、结算、广告状态提示 |
| `css/tree.css` | 科技树 |
| `css/skins.css` | 时代皮肤的通用样式（底栏托盘、实物按钮、嵌金图标），图由 `skins.js` 通过 CSS 变量传进来；个别材质的特别装饰按 `data-skin` 写 |
| `js/core/data.js` | 数值和数据表：时代、兵种、科技、颜色 |
| `js/core/save.js` · `audio.js` | 存档、声音 |
| `js/core/state.js` | 对局状态，双方共用的操作（造兵、建塔、跃迁、点科技…） |
| `js/core/sim.js` · `ai.js` | 战斗模拟、AI |
| `js/render/view.js` · `world.js` | 画布缩放和镜头；战场画面（背景、基地、单位、特效） |
| `js/render/sprites.js` · `sprite_meta.js` | 兵种像素画：选帧（走、攻击、受击闪白、死亡）和绘制；`sprite_meta.js` 是生成的格子信息。17 个时代都有像素画；单位还有卡通弹性（走路 / 呼吸 / 攻击蓄力和出手的挤压拉伸，`unitBounce`）；`world.js` 里的矢量画法只在图还没加载出来时兜底 |
| `assets/sprites/` | 兵种像素画图集 `era<N>.webp`（每种兵 12 帧 × 我方 / 敌方 / 纯白三行） |
| `tools/sprite_air_art.py` · `tools/sprite_air.py` | 17 个空军的像素造型和部件动作。每种 4 帧飞行、4 帧攻击、4 帧坠落，随 `gen_sprites.py` 打进主游戏的各时代图集。部落纪 DLC 的空军使用主游戏图集。 |
| `tools/gen_sprites.py` · `sprite_lib.py` · `sprite_parts.py` · `sprite_era<N>.py` | 生成兵种像素画和 `sprite_meta.js`：`sprite_lib.py` 是画笔、调色板、卡通大头 `cartoon_head`（大眼睛、腮红、攻击时张嘴皱眉）、卡通化后期（饱和度 +22%、左上亮边）、描边和出帧；`sprite_parts.py` 是通用部件（换装人形、头饰、武器、步兵动作、马和猛兽、车轮履带、火炮）；每个时代的 5 个兵种单独一个 `sprite_era<N>.py`，放进 `tools/` 就会被自动找到。运行 `python tools/gen_sprites.py`（全部）或 `python tools/gen_sprites.py 2 3`（只重画几个时代）。17 个时代都已画完 |
| `js/render/fx.js` · `fx_meta.js` | 受击 / 爆炸像素特效：`spawnHitFx(种类, x, y)` 放特效（近战钝击、远程命中、重击、基地受击、溅射爆炸、大招爆炸），`drawHitFx` 画；同时最多 24 个。`fx_meta.js` 是生成的帧信息 |
| `assets/fx/fx.webp` | 6 个特效的帧图集（来自 pixelfx，缩小、抽帧后打包） |
| `tools/gen_fx.py` | 把 pixelfx 导出的特效打包成 `fx.webp` 和 `fx_meta.js`。运行 `python tools/gen_fx.py <pixelfx 导出目录>` |
| `js/ui/theme.js` | 画布 HUD 用的颜色、字号（和 `css/theme.css` 对应） |
| `js/ui/hud.js` | 局内 HUD：资源面板、双方血条、小地图、训练条、大字提示。位置常量 `HUD_LAYOUT`，整体缩放 `HUD_SCALE` |
| `js/ui/skins.js` | 时代皮肤：材质表 `SKINS`、时代到材质的对照 `SKIN_OF_ERA`（17 个时代）；只预加载当前和下一步能进化到的时代；顶栏面板的材质也在这里画 |
| `assets/ui/textures/` | 17 个时代的材质图（WebP），按材质存：`<材质>.webp` 平铺纹理（顶栏面板、底栏底色），`btn_<材质>.webp` / `btn_<材质>_s.webp` 底栏按钮实物图（`_s` 是返回按钮窄版） |
| `tools/gen_textures.py` · `gen_materials.py` | 生成上面的材质图（高度图 + 打光）：前者是石板、兽皮、铁板和共用工具，后者是其余 14 种材质。运行 `python tools/gen_textures.py` 全部重新生成，需要 numpy、Pillow |
| `js/ui/icons.js` | 原创线条图标（SVG），以及底部栏按钮用哪个图标（`BAR_ICON`） |
| `js/ui/bar.js` | 底部操作栏的按钮和说明文字 |
| `js/ui/screens.js` | 页面切换、暂停、结算、战绩、设置 |
| `js/ui/tree.js` | 科技树界面 |
| `js/ui/ads.js` | 激励视频、广告奖励和上下 Banner |
| `js/ui/guide.js` · `css/guide.css` | 开局和局内图解、分步气泡。每条气泡第一次显示时写入 `save.guide`，本局仍显示到完成或到期。**加了新玩法就在 `GUIDE_STEPS` 里加一步（新 id）**；设置页可重置提示 |
| `js/input.js` | 拖动、缩放、小地图点击、键盘 |
| `js/main.js` | 主循环 |

界面按 1280×720 设计再整体缩放，手机横屏大约缩到一半，所以界面文字不小于 18px（逻辑像素）。
