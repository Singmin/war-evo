# 弹道外观映射表（各时代射手 / 炮兵 / 防御塔）

> 状态：已定稿（2026-11-08），实现见 `js/core/data.js` 的 `PROJ_STYLE`、`tools/gen_proj.py`、`js/render/arms.js`。
> 素材来源：pixelfx（MIT，https://github.com/patch-gg/pixelfx），许可证副本在 `assets/fx/PIXELFX-LICENSE.txt`。

## 问题

改造前，兵的弹道（含炮兵）17 个时代都是同一个圆点 + 拖尾，只换颜色；防御塔只有 3 种外形（曳光线 / 粗线 / 铁球），只换配色。
部落纪的投石和核能纪的炮弹看起来一样，很出戏。

## 规则

- 每个时代 5 个弹道位：射手、炮兵、轻塔、中塔、重塔 → 一共 85 个。
- 每个弹道位 = **飞行体**（循环帧，沿弹道飞、朝飞行方向转）+ **命中特效**（复用 `spawnHitFx`）+ 可选 **枪口火光**。
- **来源**：**P** pixelfx 原样，**P改** pixelfx 换色 / 缩放，**自绘** 我们自己的像素画（pixelfx 没有矛、飞镖、虫类、种子）。
- **瞬发**（电弧、藤鞭、光束）：没有飞行段，从发射点到目标画一道持续很短的线 / 光束。

## 实现要点

- **数据**：`PROJ_STYLE[时代] = [射手, 炮兵, 轻塔, 中塔, 重塔]`，每项 `{ fly, hit, muzzle?, s?, beam? }`。改外观只改这张表。
- **图集**：`tools/gen_proj.py` 把 pixelfx 导出的飞行帧缩小、去空白、按需换色，加上自绘弹体，打包成 `assets/fx/proj.webp` + `js/render/proj_meta.js`。
- **一次性序列**（`cannonball`、`homing-missile`、`magic-missile`、`boulder`）：只截取中段飞行帧当循环。
- **命中**：新增的命中特效（酸液、孢子、电击、等离子、内爆、手雷、小爆炸、油桶、小核爆、子弹命中、中毒）加进 `tools/gen_fx.py` 的 `FX` 表。
- **尺寸**：飞行体缩到约 8–28 逻辑像素长（兵高约 44），按 `FX_SCALE` 不插值放大，和兵种像素画一致。
