**One-sentence pitch:** 人类文明毁灭之后，两派幸存者从石器时代重新起步，在同一条战线上比拼谁进化得更快。（设计文档 §1）

## Core loop
- 花金币造兵（队列最多 5 个）→ 兵自动沿战道推进 → 相遇交战，击杀得金币（兵价 ×0.5）和经验（兵价 ×2）
- 经验攒满得科技点；4 点 + 一笔金币（230 / 430 / 780 / 1300）跃迁到下一个时代，期间训练暂停 3 秒
- 同一份金币在造兵、建塔 / 扩塔位 / 强化、采矿场、跃迁之间分配——"每个按钮都不应该一亮就点"（设计文档 §2.1）

## Player goal & fail state — what "working" looks like
- 摧毁对方基地获胜，己方基地被毁即失败；双方都进入最终时代 25 秒后进入"决战"：双方基地每秒掉 0.8%，打基地伤害每分钟 +50%，保证对局在 8–15 分钟内结束

## MVP — what must exist to be the game
- 对线战斗：5 兵种克制环（步→骑→炮→重→射→步，克制 ×1.6）、3 种塔、大招 — **built (M1)**
- 时代科技树：17 个时代、3 条路线、9 个最终时代、34 个科技 — **built**
- 经济决策：采矿场 3 级（每级 +15%）、塔强化 2 级、塔位扩建到 4 个 — **built (M2)**
- AI 对手：简单 / 普通 / 困难，落后时享受追赶加成 — **built (M2)**
- 局内剧情：开局、每次跃迁、决战、结算的对话框和结局选择 — **not built (M3)**；文本在 `docs/剧情.md`
- 手机横屏可玩、TapTap H5 发布 — **partial (M4)**：横屏布局和触控已有，真机测试和 SDK 未做

## Design decisions (confirmed by the author, 2026-11-08)
1. **AI 追赶加成** — 有意为之，只为让 AI 不掉队；不向玩家提示。保留 `CATCH_UP` 现状。
2. **看广告换科技点不限次** — 保持不限次，变现优先。
3. **抢先跃迁奖励** — 要做。奖励内容待作者给出（未实现，属于 MVP 之外的新增，加入构建顺序第 3 步）。
4. **科技点越拿越贵**（`PT_STEP = 1.0`）— 最终设计：想多点科技就得晚点跃迁。
5. **数值来源** — 以 `docs/设计文档.md` 为准；`js/core/data.js` 与文档不一致的地方是代码要改。下一步用 `/balance-check` 找出所有不一致。
6. **对局时长不设目标**（2026-11-12）— 不再要求对局在 8–15 分钟内结束；打得久没关系，玩家可以看广告增强来打破僵持。上面"Player goal"里的 8–15 分钟说法以此为准。
