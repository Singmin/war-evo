# 部落纪·大头圆脸 DLC

可选兵种外观，默认关闭。在游戏的「设置 → 兵种外观」中启用；
可随时切回原版，选择会保存。只改变部落纪五个兵种的外观，不改变战斗数值。

`era0.webp` 与 `manifest.json` 由 `python tools/build_era0_dlc.py` 一起生成。
图集和画格信息均加载成功后才生效，失败时保留当前外观。
主游戏的 `assets/sprites/era0.webp` 仍由 `python tools/gen_sprites.py 0` 生成。

当前是已选定单姿势样稿的轻量动效预览，尚无独立的迈腿、挥棒和投石脱手帧。
源图与规格见 `tools/art-source/era0-v4/`。此处只提供本地外观包，没有付费或商店接入。
